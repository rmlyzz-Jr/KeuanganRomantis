# 💰 Keuangan Pro - Atur Uang & Anggaran

[![PWA](https://img.shields.io/badge/PWA-Ready-blue)](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps)

Aplikasi pencatatan keuangan pribadi berbasis web yang bisa diinstal di HP dan PC.

## ✨ Fitur Utama
- 📊 Dashboard dengan grafik interaktif
- 🎯 Manajemen Anggaran per kategori
- 🏦 Multi-Rekening (Tunai, Bank, E-Wallet)
- 📋 Riwayat Transaksi dengan filter
- 📤 Export Laporan (CSV)
- 📱 PWA - Bisa diinstal di HP/PC
- 🔒 Sistem Login & Register
- 📜 Audit Log untuk admin

## 📱 Cara Instal
### Di HP (Android)
1. Buka Chrome/Edge
2. Kunjungi URL aplikasi
3. Klik menu → "Add to Home Screen"

### Di PC (Windows/macOS)
1. Buka Chrome/Edge
2. Kunjungi URL aplikasi
3. Klik ikon install di address bar

## 🛠️ Teknologi
- HTML5, CSS3, JavaScript
- Chart.js
- PWA (Service Worker + Manifest)
